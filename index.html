04

OpenSSL Operations

Frequently used commands from the management guide.

Inspect Certificate

openssl x509 -in certificate.pem -text -noout
openssl x509 -in certificate.pem -noout -enddate
openssl x509 -in certificate.pem -noout -issuer
openssl x509 -in certificate.pem -noout -subject

PFX → PEM

openssl pkcs12 -in certificate.pfx \
  -out certificate.pem -nodes

Extract Certificate

openssl pkcs12 -in certificate.pfx \
  -clcerts -nokeys -out server.crt

Extract Private Key

openssl pkcs12 -in certificate.pfx \
  -nocerts -nodes -out server.key

Build Full Chain

cat server.crt \
  intermediate.crt \
  root.crt > fullchain.pem

Verify Chain

openssl verify \
  -CAfile fullchain.pem server.crt
05

Linux Deployment

Examples for common web and load-balancing platforms.

server {
  listen 443 ssl;
  ssl_certificate /etc/ssl/fullchain.pem;
  ssl_certificate_key /etc/ssl/server.key;
}

nginx -t
systemctl reload nginx
SSLCertificateFile /etc/httpd/ssl/server.crt
SSLCertificateKeyFile /etc/httpd/ssl/server.key
SSLCertificateChainFile /etc/httpd/ssl/intermediate.crt

systemctl restart httpd
cat server.key server.crt \
  intermediate.crt > haproxy.pem

bind *:443 ssl crt /etc/haproxy/haproxy.pem
systemctl restart haproxy

Troubleshooting

Common SSL issues and first checks.

01

Unable to Load Certificate

Inspect the certificate with OpenSSL and confirm the encoding is valid.

02

Key Mismatch

Compare certificate and private-key moduli to confirm they belong together.

03

Incomplete Chain

Use openssl s_client to inspect certificates presented by the server.

04

Certificate Expired

Check the certificate end date and renew before production expiration.

✓

Production Best Practices

  • Keep private keys secure and never email private keys.
  • Maintain certificate inventory and automate expiry monitoring.
  • Verify certificate chains before deployment.
  • Use strong TLS versions and renew before expiration.
  • Store certificate and key backups securely.

Quick Reference

Essential commands from the complete README.

# View certificate
openssl x509 -in cert.pem -text -noout

# Check expiry

# PFX to PEM
openssl pkcs12 -in cert.pfx -out cert.pem -nodes

openssl pkcs12 -in cert.pfx -nocerts -nodes -out key.pem

# Verify chain
openssl verify -CAfile fullchain.pem server.crt

# Test SSL
openssl s_client -connect hostname:443 -showcerts
